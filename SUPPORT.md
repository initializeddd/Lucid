# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/initializeddd/Lucid/discussions) for questions,
workflow advice and early ideas. Discussions are a better fit than the issue tracker for anything
that is not a confirmed, reproducible problem.

## Bugs and feature requests

Open an issue with the matching form:

- [Bug report](https://github.com/initializeddd/Lucid/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/initializeddd/Lucid/issues/new?template=feature_request.yml)
- [Accessibility report](https://github.com/initializeddd/Lucid/issues/new?template=accessibility.yml)

Include the Lucid version, platform, steps to reproduce and any relevant logs. Do not include
private code, credentials or personal information.

## Security

Do not open a public issue for a security problem. Follow [SECURITY.md](SECURITY.md) and use the
repository's private vulnerability reporting channel.

## Documentation

Installation, build and architecture guides are published at
<https://initializeddd.github.io/Lucid/>.

## Commercial support

Commercial support is not currently offered.
