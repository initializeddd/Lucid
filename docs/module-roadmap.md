# Requested module roadmap

The following 30 modules are the scope requested for this work. A module is not
complete until its listed workflow is implemented, verified, and its package is
published and installable in Lucid. Current implementations remain in progress;
see `modules.md` for specific limitations. No new package in this roadmap has
been published yet.

1. CMake Navigator — targets, sources, includes, definitions and build options.
2. Test Coverage Lens — line coverage and navigation to gaps.
3. Secret Scanner — likely credentials and pre-commit warnings.
4. Dependency Risk Review — advisories and dependency provenance.
5. Custom Snippets — reusable templates and editable placeholders.
6. Markdown Studio — preview, heading navigation and link checking.
7. Pull-Request Companion — pull requests, comments, files and checks.
8. Container Tools — project containers, logs and configured actions.
9. Python Environments — detect, create and select environments and interpreters.
10. Embedded C/C++ — firmware memory, linker maps, registers and cross targets.
11. Microcontroller Dashboard — board detection, flashing and serial output.
12. Rust Ownership Lens — borrow diagnostics and ownership context.
13. SQL Workbench — queries, results and execution plans.
14. API Request Studio — saved HTTP requests, variables and responses.
15. Test Runner Plus — test discovery, individual runs, failures and history.
16. Visual Regression Review — screenshot comparison and approvals.
17. Benchmark Comparison — measurements and possible regressions.
18. Hex Editor — inspect and cautiously edit binary files.
19. Binary Inspector — architecture, sections, symbols and libraries.
20. Crash Dump Reader — crashes, stack frames and source navigation.
21. Log Correlation — search and align multiple service logs.
22. Shader Workbench — compile, diagnostics and preview.
23. Web Component Preview — isolated components at different sizes and states.
24. Accessibility Test Runner — automated checks linked to code.
25. Localization Workspace — missing translations and long or RTL text preview.
26. Design-Token Explorer — tokens and their usages.
27. Change Archaeology — file or function evolution across Git history.
28. Release-Note Builder — selected commits and tasks into an editable draft.
29. Diagram-as-Code Preview — render supported diagrams beside source.
30. Local Error Explainer — explain compiler or debugger errors locally.
